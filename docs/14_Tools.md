# Tools

Version: 1.0

---

# Назначение

Tools являются интерфейсом NeuroCore к внешнему миру.

Все действия, которые влияют на внешнюю среду или используют внешние библиотеки, выполняются исключительно через Tools.

Никакой компонент системы не должен напрямую обращаться к:

- Python;
- Shell;
- Git;
- браузеру;
- сети;
- файловой системе;
- LLM;
- базам данных;
- API.

Все взаимодействия проходят через Tool Interface.

---

# Главная задача

Предоставить единый, безопасный и расширяемый интерфейс для выполнения внешних операций.

```
Planner

↓

Execution

↓

Tool API

↓

Concrete Tool

↓

External World
```

---

# Главный принцип

Любой внешний механизм является Tool.

Не существует "особых" инструментов.

Python — такой же Tool, как:

- Shell;
- Browser;
- Git;
- HTTP;
- Docker;
- OCR;
- SQLite.

Архитектура не зависит от конкретных технологий.

---

# Архитектура

```
                 Tools

                    │

             Tool Manager

                    │

             Tool Registry

                    │

       ┌────────────┼────────────┐

       │            │            │

   Python Tool  Git Tool   Browser Tool

       │            │            │

       └────────────┼────────────┘

                    │

             External Systems
```

---

# Tool Manager

Tool Manager отвечает за:

- регистрацию;
- поиск;
- запуск;
- остановку;
- управление ресурсами;
- контроль выполнения;
- журналирование.

---

# Tool Registry

Registry хранит информацию обо всех инструментах.

Минимальные поля:

```
Tool ID

Name

Version

Capabilities

Permissions

Status

Provider
```

Registry не хранит состояние выполнения.

---

# Tool Interface

Все инструменты реализуют одинаковый интерфейс.

Минимальный набор методов.

```
Init()

Execute()

Validate()

Cancel()

Health()

Shutdown()
```

Execution работает только через этот интерфейс.

---

# Capability

Каждый Tool объявляет свои возможности.

Например.

```
Python.Execute

Shell.Execute

Browser.Open

Git.Clone

Git.Commit

HTTP.GET

HTTP.POST

Filesystem.Read

Filesystem.Write

OCR.Read

Image.Resize
```

Planner использует Capability при построении плана.

# Python Tool

Python является одним из инструментов.

Он используется только тогда, когда выполнение действительно требует Python.

Например

- анализ данных;
- работа с NumPy;
- построение графиков;
- машинное обучение;
- научные вычисления.

Python не должен использоваться для задач, которые быстрее решаются на C.

---

# Shell Tool

Shell используется для:

- запуска программ;
- выполнения команд;
- автоматизации;
- взаимодействия с системой.

Shell работает в изолированной среде.

---

# Git Tool

Git Tool предоставляет операции.

Например

```
Clone

Commit

Checkout

Diff

Merge

Status

Branch
```

Planner не должен знать команды Git.

Он знает только Capability.

---

# Browser Tool

Browser используется для:

- открытия страниц;
- получения HTML;
- взаимодействия с веб-интерфейсами;
- автоматизации браузера.

---

# LLM Tool

LLM является обычным инструментом.

Он используется для:

- анализа естественного языка;
- генерации текста;
- классификации;
- извлечения знаний;
- суммаризации.

LLM никогда не является ядром NeuroCore.

При отсутствии LLM архитектура продолжает работать.

---

# Tool Selection

Execution никогда самостоятельно не выбирает инструмент.

Выбор производится Planner.

Execution получает уже выбранный Tool.

---

# Выполнение

Общий цикл выполнения.

```
Plan Step

↓

Tool Selection

↓

Execute

↓

Result

↓

Observation

↓

Memory
```

---

# Результат выполнения

Каждый Tool возвращает единый результат.

```
ToolResult

├── Status
├── Exit Code
├── Output
├── Error
├── Duration
├── Metadata
└── Artifacts
```

Execution работает только с ToolResult.

---

# Ошибки

Любая ошибка инструмента становится объектом Error.

Она содержит:

- Tool ID;
- входные параметры;
- сообщение;
- стек (если существует);
- время;
- код ошибки.

---

# Разрешения

Каждый Tool работает с минимально необходимыми правами.

Например.

```
Filesystem

Read Only

Shell

Restricted

Network

Allowed

GPU

Denied
```

Принцип минимальных привилегий обязателен.

---

# Изоляция

Каждый Tool должен быть максимально независим.

Инструмент не имеет права:

- изменять Memory;
- обращаться к другим Tool напрямую;
- изменять Runtime;
- изменять Planner.

Все взаимодействия проходят через Execution и IPC.

---

# Таймаут

Каждый вызов Tool имеет ограничение по времени.

При превышении:

- выполнение отменяется;
- создаётся Error;
- Planner получает уведомление.

---

# Повторное выполнение

Некоторые Tool поддерживают Retry.

Например

```
HTTP Request

↓

Timeout

↓

Retry
```

Политика Retry определяется Planner.

---

# Производительность

Tool Manager собирает статистику.

Например

- среднее время выполнения;
- количество ошибок;
- успешность;
- использование памяти;
- использование CPU.

Learning использует эту информацию.

---

# Журналирование

Каждый вызов Tool журналируется.

Минимально сохраняются:

- время;
- Tool;
- параметры;
- длительность;
- результат;
- ошибка.

---

# Инварианты

Tools обязаны соблюдать следующие правила.

- Любое внешнее действие выполняется через Tool Interface.
- Все Tool имеют единый интерфейс.
- Все Tool объявляют Capability.
- Все Tool работают изолированно.
- Все Tool возвращают ToolResult.
- Все ошибки становятся Error.
- Planner выбирает Tool.
- Execution выполняет Tool.
- Все вызовы журналируются.

---

# Заключение

Tools являются единственной точкой взаимодействия NeuroCore с внешним миром.

Они скрывают детали конкретных технологий за единым интерфейсом, обеспечивая модульность, безопасность и независимость архитектуры от используемых библиотек, языков программирования и внешних сервисов.

Благодаря этому система может легко расширяться новыми инструментами без изменения ядра.
