# Learning

Version: 1.0

---

# Назначение

Learning является подсистемой самообучения NeuroCore.

Его задача — изменять систему знаний на основании накопленного опыта.

Learning не заменяет Understanding.

Learning не заменяет Reasoning.

Learning не принимает решения.

Learning изменяет качество памяти.

---

# Главная задача

Преобразовывать опыт системы в улучшение знаний.

```
Experience

↓

Learning

↓

Memory Update

↓

Better Future Decisions
```

---

# Главный принцип

Learning никогда не создаёт знания "из воздуха".

Любое изменение должно основываться на:

- опыте;
- статистике;
- подтверждении;
- результатах выполнения;
- успешности применения знаний.

---

# Что изменяет Learning

Learning может изменять:

- уровень доверия;
- силу связей;
- приоритет знаний;
- статистику использования;
- вероятность выбора алгоритмов;
- вероятность выбора планов;
- уровень активации;
- уверенность гипотез.

Learning не изменяет смысл знаний самостоятельно.

Если смысл знания изменился — создаётся новая версия Knowledge Object.

---

```

```

# Общий цикл

```
Episode

↓

Observation

↓

Statistics

↓

Experience

↓

Pattern Discovery

↓

Memory Update
```

Learning работает постоянно.

---

# Источники обучения

Learning получает информацию из:

- Episode;
- Observation;
- Error;
- Planner;
- Execution;
- Reasoning;
- Understanding;
- пользователя.

Все подсистемы способны обучать систему.

---

# Experience Collector

Собирает опыт.

Например

```
100 выполнений алгоритма

↓

Experience
```

или

```
500 успешных планов

↓

Experience
```

или

```
100 ошибок

↓

Experience
```

---

# Statistics Analyzer

Анализирует статистику.

Например

- частоту использования;
- успешность;
- ошибки;
- скорость;
- стоимость;
- количество повторений.

Статистика является одним из главных источников обучения.

---

# Pattern Discovery

Ищет закономерности.

Например

```
Алгоритм A

чаще успешен

чем

Алгоритм B
```

или

```
После действия X

почти всегда

следует ошибка Y.
```

Pattern Discovery создаёт Hypothesis.

---

# Confidence Estimator

Изменяет уровень доверия.

Например

```
Knowledge

Trust

0.62

↓

0.78
```

или

```
0.81

↓

0.43
```

Изменение доверия должно быть постепенным.

---

# Relation Optimizer

Изменяет силу связей.

Например

```
Knowledge A

↓

Knowledge B

Weight

0.20

↓

0.84
```

Часто используемые связи усиливаются.

Редко используемые ослабевают.

---

# Memory Optimizer

Оптимизирует память.

Например

- архивирует редко используемые знания;
- удаляет повреждённые индексы;
- объединяет дубликаты;
- пересчитывает статистику;
- обновляет кэш.

---

# Обучение на успехах

Успешное выполнение увеличивает доверие.

Например

```
Algorithm

↓

Executed

↓

Success

↓

Confidence++
```

---

# Обучение на ошибках

Ошибки являются одним из важнейших источников обучения.

Например

```
Plan

↓

Execution

↓

Failure

↓

Error

↓

Learning
```

Ошибка никогда не удаляется.

Она становится частью опыта.

---

# Обучение на повторениях

Если система многократно наблюдает одну и ту же закономерность,

доверие постепенно увеличивается.

Learning никогда не повышает доверие скачком.

---

# Обучение на противоречиях

Если обнаруживаются конфликтующие знания,

Learning не удаляет ни одно из них.

Он:

- уменьшает доверие;
- создаёт связь ConflictsWith;
- сообщает Reasoning.

---

# Обучение пользователя

Пользователь является источником знаний.

Но пользователь не является абсолютным источником истины.

Информация проходит те же стадии:

```
User

↓

Understanding

↓

Knowledge

↓

Validation

↓

Memory
```

---

# Забывание

Learning отвечает за контролируемое забывание.

Забывание не означает удаление.

Возможные варианты:

- снижение активации;
- перенос в архив;
- уменьшение приоритета;
- сжатие статистики.

Удаление используется крайне редко.

---

# Самооценка

Learning анализирует эффективность самой системы.

Например

- среднее время поиска;
- успешность планирования;
- успешность дедукции;
- качество аналогий;
- качество гипотез.

Это позволяет постепенно улучшать работу NeuroCore.

---

# Обновление алгоритмов

Learning может изменять рейтинг алгоритмов.

Например

```
QuickSort

Score

0.82

↓

0.91
```

или

```
DFS

↓

0.40
```

Planner использует эти оценки.

---

# Обновление Planner

Learning может изменить:

- стоимость плана;
- вероятность успеха;
- оценку риска;
- рекомендуемый алгоритм.

Сам Planner не обучается.

Он использует знания Learning.

---

# Обновление Reasoning

Learning не изменяет код Reasoning.

Он изменяет знания, которыми пользуется Reasoning.

Поэтому качество мышления постепенно улучшается.

---

# Ограничения

Learning запрещено:

- изменять Knowledge ID;
- удалять историю;
- изменять происхождение знаний;
- изменять смысл знания без создания новой версии;
- обходить Memory API.

---

# Производительность

Learning не должен замедлять работу системы.

Большинство операций выполняются асинхронно.

Длительные перерасчёты могут выполняться в фоне.

---

# Инварианты

Learning обязан соблюдать следующие правила.

- Работает только через Memory API.
- Использует Episode как основной источник опыта.
- Не удаляет знания без веских причин.
- Изменяет доверие постепенно.
- Не меняет смысл знаний напрямую.
- Усиливает полезные связи.
- Ослабляет бесполезные связи.
- Все изменения журналируются.

---

# Заключение

Learning является механизмом долговременного развития NeuroCore.

Он не принимает решения и не выполняет рассуждений.

Его задача — сделать систему умнее завтра, чем она была вчера, используя собственный опыт, накопленные знания и результаты взаимодействия с окружающей средой.
